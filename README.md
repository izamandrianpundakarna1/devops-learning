# DevOps Learning
Kumpulan latihan Python dasar dan project backup otomatis, sebagai bagian dari perjalanan menuju DevOps Engineer.

Daftar isi project:
1.kalkulator.py: menjalankan operasi matematika dasar '+ - * / % ** //' dengan input dua angka dan satu operator. Sudah dilengkapi try-except untuk input tidak valid dan pembagian dengan nol.
2.simple project 1.py: membuat backup otomatis sebuah folder ke lokasi lain (D:\ atau Documents), dengan nama 'nama-folder_backup_tanggal'. Menyalin file dan subfolder, menangani folder backup yang sudah ada, dan menampilkan laporan jumlah file.
3.list.py: program daftar belanja dengan menu tambah, hapus, lihat daftar (bernomor), dan keluar. Pencarian tidak peduli huruf besar-kecil.
4.perkalian.py: menampilkan tabel perkalian 1 sampai 10 untuk angka yang dimasukkan user.
5.prima.py: mengecek apakah sebuah angka genap/ganjil dan apakah bilangan prima.
6.tebak angka.py: game tebak angka 1 sampai 100 dengan petunjuk “terlalu kecil” atau “terlalu besar” dan penghitung jumlah tebakan.

Cara menjalankan: versi Python (3.11) dan perintah, misalnya python "simple project 1.py"

Contoh penggunaan simple project 1.py:
```
masukkan path yang ingin diback-up: C:\Users\62812\Documents\css grid
path C:\Users\62812\Documents\css grid adalah folder
folder backup berhasil dibuat
Backup dari C:\Users\62812\Documents\css grid selesai
Total file di folder : 3
Di dalam subfolder : 1
```
